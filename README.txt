NEXUS V2 — Dashboard prototype

WHAT'S NEW
- Dedicated NEXUS Assistant panel with a calm, measured British-English personality.
- Browser speech output where supported; it uses voices available on the device.
- Optional browser speech input where supported and permitted.
- Knowledge Bank that saves notes in this browser's local storage.
- Evolution blueprint describing review, research, testing and approval gates.

IMPORTANT LIMITATIONS
- This is a front-end prototype, not a connected AI assistant.
- Assistant replies are local demonstration responses, not generated by an LLM.
- The activity feed is illustrative, not live background research.
- Knowledge Bank notes stay in the current browser/device and are not synced.
- Voice uses browser speech features; actual voice availability varies by device/browser.
- No live market data, Vantage connection, MT5 integration or order execution exists.
- Do not treat this prototype as financial advice or a trading system.

PUBLISHING TO YOUR EXISTING GITHUB PAGES SITE
1. Extract this ZIP.
2. Open your GitHub repository: nexus-command-centre.
3. Replace the existing root-level index.html with this new index.html.
4. Commit the change.
5. GitHub Pages should redeploy automatically. Refresh the site after deployment.

The file is self-contained and has no external libraries or API keys.
