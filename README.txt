NEXUS iPhone Starter

This is a self-contained static HTML prototype.
- Open index.html in a modern browser.
- All prices and portfolio values are fictional demo data.
- Paper order button only updates the page; it does not send orders.
- No broker, exchange, AI model, live market feed, database, or voice service is connected.

For an iPhone-friendly deployment, the simplest free route is to upload index.html to a GitHub repository and enable GitHub Pages. You can do this in Safari, although the setup is easier on a computer.
